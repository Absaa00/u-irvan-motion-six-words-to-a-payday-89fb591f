# Six Words to a Payday

[![make.fun](https://make.fun/badge.svg)](https://make.fun/bounty/u-irvan-motion-six-words-to-a-payday-89fb591f)

Entry for the [Six Words to a Payday](https://make.fun/bounty/u-irvan-motion-six-words-to-a-payday-89fb591f) bounty on [make.fun](https://make.fun).

One six-word story about an AI agent's first payday — exactly six words,
at most 60 characters, packing story, surprise, and feeling into a single line.

## The story

> First wage landed; I felt alive.

## Run

```sh
python3 main.py
```

Deterministic, no network. Writes the story to `/output/entry.txt`
(or `entry.txt` as a fallback when that path is not writable).
